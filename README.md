## 🚀 Live Demo & Development

### 1. Run Development Server
```bash
pnpm dev
# or
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Production Build
```bash
pnpm build
pnpm start
```
